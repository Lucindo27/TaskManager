# Task Manager - CRUD Application (C# + SQL Server)

## 📌 About the Project

This is a simple Task Manager application built using C# and SQL Server.
The system allows users to create, list, update and delete tasks.

The main goal of this project is to practice:
- Database connection
- Data manipulation (CRUD operations)
- Clean code structure using ADO.NET

---

## 🚀 Features

- Add new tasks
- View all tasks
- Update existing tasks
- Delete tasks
- SQL Server database integration

---

## 🛠 Technologies Used

- C#
- .NET
- SQL Server
- ADO.NET

---

## ⚙ How to Run

1. Clone the repository
2. Create a SQL Server database
3. Update the connection string in `Conexao.cs` if necessary
4. Run the project
